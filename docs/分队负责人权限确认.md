# 分队负责人权限确认

2026-10-26，按用户确认的范围增量开发，保留 FastAPI、MySQL 和现有服务记录计时机制。

## 已确认

- 咨询服务一至七分队分别设置负责人；美育设置一位负责人，覆盖周一至周日。
- 负责人仅有本范围人员、排班、时长查询及导出，考勤登记与改判，时段管理员及容量设置，队员密码重置和操作日志查询权限。
- 不开放个人信用手动调整、服务时长直接修正、人员时段归属调整、长期换班终审；禁止修改信用规则。
- 跨分队调整、业务目录、全局学期日历、时长征集及专项导入不继承全局超管权限。
- 负责人可初审退队申请，全局超管保留最终审批。
- 日报保留周结算，分别显示当日预计时长、当日已认定时长、管辖范围累计已认定时长。
- 普通管理员可上调所有固定时段业务中本人管理时段的时长；仅限已结束且正常出勤或迟到的服务，必须高于当前认定或预计时长，说明必填。
- 调整立即保存；未结算的调整在周结算入账，不提前生成服务时长。咨询通知分队负责人，美育通知美育负责人，其他业务通知全局超管。

## 后续确认

- 咨询服务队员只能属于一个分队；本范围负责人初审，全局超管终审。
- 仅提供任命入口，由用户指定现有队员；不创建测试负责人账号。
- 核对发现 42 名历史队员跨分队，用户确认保留排班与时长、禁止扩大跨队归属；待名单核对前，这些队员退队由全局超管直接审核。

本文件记录用户确认过程；实现、权限及迁移说明见《分队与美育负责人_2.4.0.md》。

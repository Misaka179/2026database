# 业务目录与小组管理（2.3.0）

更新日期：2026-10-26。保留 FastAPI、MySQL 和原生前端，继续从有效服务记录汇总整数分钟。

## 使用入口

- **业务与人员 → 业务管理 → 新增业务**：可独立新增非固定业务，或填写多个固定时段。固定时段配置星期、编号（1—100）、起止时间、认定分钟、容量和普通管理员；同业务同日时段不可重叠。队员归属仍在基础资料调整，并校验跨业务时间冲突。新业务从创建时开始生效，不补算此前时长。
- **业务管理 → 停用归档**：先显示待处理事项及将取消的未来排班数量，填写原因后确认。开放征集、待审核申报、未完成请假／换班／退队／管理范围申请，以及涉及本业务的待生效归属调整会阻止归档。历史和已开始服务保留；花园保留当前周，后续周停止。
- **业务管理 → 恢复业务**：只恢复允许重新安排的未来服务。停用期间不补计，手动取消、退队等其他原因取消的排班不会恢复。归档业务仍可查历史、导出和更正历史，不能新增人员归属、征集或导入。
- **业务与人员 → 小组与成员**：查询八个小组、调整成员及导入名单。允许兼任，按生效区间保留历史；原有未指定小组成员单列为“未分组”。
- **申请与审批 → 征集管理范围**：超级管理员可以指定整个业务或多个小组；普通管理员可申请范围，超管批准后生效。整业务授权覆盖全部小组。固定业务考勤管理员仍在时段／业务设置中配置。
- **时长与信用 → 时长征集**：整业务管理员或超管可选择整个业务或一个小组；小组管理员只能选择授权小组。小组征集参与名单必须属于该组，发布时冻结。管理员初审，超管终审通过后计时；历史未分组征集只由整业务管理员和超管管理。
- **时长与信用 → 服务时长**：支持业务、小组及“未分组”筛选，显示分业务和分组分钟合计。原三张 Excel 报表保留每周日期表头，支持自定义时段、业务／小组分组和筛选。每条服务只计入一个小组，调组不改变既有征集的时长归属。

## 名单导入

入口为“小组与成员 → 导入业务／小组名单”。上传包含“姓名、学号”表头的 XLSX，可选“学院”；逐表选择目标业务／小组或跳过，核对后点击确认导入。映射或身份处理改变后须重新核对。学号按文本处理，保留前导零。

系统不覆盖已有账号姓名、密码、信用或历史。缺失学号、同学号姓名冲突、同名不同学号、不在队账号等会提示；须修正或明确跳过。新账号需要填写初始密码，密码不写日志。名单只增加归属，不计服务时长，不清除文件未列出的成员，也不授予管理员权限。同一导入内容、映射及核对结果再次提交会返回原批次。

本次 `干事名单.xlsx` 的映射：综运→综合运营中心、图志之家→图志之家、活策→活动策划中心、物资采购→物资采购中心、宣传→宣传推广中心、音视频→音视频制作中心、摄影摄像→摄影摄像中心、青广→青广干事；明远学术→明远学术汇。青广工作表不调整青广宣传固定排班；开心花园空表跳过。

## 菜单

“工作概览”和“收件箱”保持直达，其余分为“业务与人员”“排班与考勤”“时长与信用”“申请与审批”“系统管理”。点击模块标题展开／收起；键盘可聚焦并按 Enter 或空格，手机直接触摸。按身份过滤空模块，折叠状态按身份记在本浏览器中；跳转页面时展开所在模块。志愿者不能访问全局服务班次。

## 迁移和开发位置

- 新增 `directory_schema.py`，迁移标记 `business_directory_v1`。新增6张表：business_window、business_group、group_member、collection_group_manager、member_import、member_import_row。总计42张表。business增加状态和版本，征集、排班及范围申请增加可空group_id。
- 原“干部”更名为“干部及干事”，保留业务ID、归属、授权、历史；旧名称提交映射到同一业务。启动种子不会重新生成“干部”，不会重新激活归档业务。
- 业务启用区间保存在business_window，自动排班依据服务开始时刻检查区间；花园以该周周一判断启用区间，统计日期仍为周日。排班归档取消原因使用BUSINESS_ARCHIVED，其他取消原因不覆盖。
- 新增业务生命周期及小组接口在 `api.py`、`directory.py`；名单预览／确认在 `member_import.py`；前端 `directory-ui.js`。范围和附件权限扩展在现有征集模块，未建立新的时长账本。
- 正式迁移前备份数据库；附件在数据库BLOB中，备份含附件。隔离库 `volunteer_core_test` 验证迁移两次，核对所有旧字段数据指纹（仅允许干部名称更改），有效时长及信用流水不变后再应用正式库。不得重建正式库。
- 验证记录：项目上级 `.work/directory-regression.log`（171项回归），`.work/directory-final-tests.log`（16项补充验证），`.work/directory-ui-smoke.json`（完整页面流程）。界面截图位于 `outputs/directory-20261026/`。迁移及正式导入结果分别记在 `.work/directory-upgrade-verification.json`、`.work/directory-roster-volunteer_core.json`。

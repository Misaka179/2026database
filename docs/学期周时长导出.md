# 学期周时长导出

超级管理员进入“服务时长”，点击“导出学期周时长”，选择学期并下载 Excel。普通管理员和志愿者没有此权限。导出范围为所选学期全队，不受页面个人查询、起止日期筛选影响。

## 格式

参考提供的时长统计表，生成“志愿时长统计”“分队时长统计”“退队统计”三个工作表。明细保留姓名、业务、分类、学院、文本学号、每周时长、个人学期总计、个人备注。周数取学期的结束周次，不固定为模板的24周。

“第1周”是开工日所在的周一至周日，每个周表头同时显示完整日期范围，包括跨年日期；开工日前不计时。一人多个时段分行，时长归入实际服务记录所属时段；每行总计只累计该行，跨行相加才是该人的学期总计。当前归属及学期内历史排班时段均保留，避免长期换班后丢失旧时段记录。

## 统计口径

- 以实际服务日期分周，调休也按实际日期归周。
- 只累计有效服务记录，使用修正后的分钟数换算小时；已作废记录不累计。
- 缺勤、请假无有效时长即计0；节假日停工不产生时长。
- 已到周无记录显示0；当前周只含已认定记录，未来周留空，不预填预计时长。
- 已退队人员单列“退队统计”，其历史有效时长仍计入分队和全队汇总。停用人员在明细备注标明。
- “业务”沿用参考表的“咨询服务”；系统未保存原表中的更细业务岗位。
- 导出只读取系统数据，不导入参考表中的旧时长，不改动数据库。系统每分钟的自动结算仍按原机制运行。

接口：`GET /hours/export?semester_id=学期编号`，使用登录令牌；响应为 `.xlsx` 附件且禁止缓存。

# 简体中文工作台与接口文档

## 页面入口

- `/`：图书馆志愿服务管理工作台。
- `/password`：找回密码页（提交重置申请；修改密码在登录后的工作台「修改密码」弹窗中进行）。
- `/docs`：中文接口文档与调用页面。
- `/redoc`：跳转到 `/docs`，兼容旧入口。

在工作台选择“管理员”或“志愿者”身份，再使用本地演示账号登录。管理员身份根据后端返回的实际角色区分普通管理员与超级管理员。账号示例和启动方法见上级 `README.md`，随机密码保存在工作区 `.work/demo-accounts.json`，页面不内置演示密码。

## 角色与页面

| 页面或操作 | 志愿者 | 普通管理员 | 超级管理员 |
|---|---|---|---|
| 工作概览 | 本人排班、时长、信用及申请 | 负责班次的排班和审批待办 | 全局排班、在队人数及审批待办 |
| 排班与考勤 | 本人记录，发起请假和换班 | 负责班次新增/取消排班、结束后登记考勤 | 新增/取消排班及查询 |
| 申请与审批 | 本人申请和处理进度 | 负责班次请假审批、换班初审 | 换班终审、退队审批和查询 |
| 服务时长 | 查询本人记录 | 不开放 | 按学生查询，填写原因后修正 |
| 信用管理 | 本人信用与流水 | 不开放 | 按学生查询流水、查看和发布规则版本 |
| 基础资料 | 不开放 | 不开放 | 维护队员资料、创建管理员；导入和新增队员已移到业务管理的班次/小组成员名单 |
| 业务管理 | 不开放 | 作为业务负责人时管理自己负责的整个业务：查看全部时段、成员、考勤与时长，添加/修改时段与容量、设置时段负责人、建小组与调整成员、导入名单、按批次查看导入记录并撤销 7 天内的导入、在班次/小组名单行内移出队员、发布/关闭时长征集、任命本业务分队负责人、指定小组征集负责人、审批时长上调/请假/换班；不能给自己任命、改名、归档，也不能操作其他业务 | 新增/改名/归档业务、指定业务负责人；「服务班次」页按星期折叠查看，每个星期一行独立的分队负责人（行内「设置负责人/修改负责人」，按业务×星期写入管理范围，与时段负责人相互独立），右上角「添加时段」旁显示「总负责人：姓名」或「设置总负责人」；非固定业务在小组页同样显示该入口；小组管理页可添加小组、给小组指定征集负责人（合并该管理员原有范围）；班次成员与小组成员名单页可导入、新增或移出队员（超管与业务负责人可见） |
| 服务班次 | 查看班次设置 | 查看班次设置 | 在基础资料中查看和设置负责人、容量 |
| 操作日志 | 不开放 | 不开放 | 查看最近操作和修改前后值 |
| 密码管理 | 本人可提交重置申请；登录后可改密 | 同左 | 同左，并可重置他人密码 |

这些页面入口只负责呈现工作范围。每次接口请求仍重新检查登录者、权限和业务状态；隐藏按钮不能替代服务端权限校验。信用归零或退队的志愿者保留历史查询权限。

## 业务管理名单接口

| 方法 | 路径 | 用途 | 权限 |
|---|---|---|---|
| POST | `/students/import` | 固定业务名单导入；传 `slot_id` 时全员归该班次，不传则按表格中的分类/时段列映射 | 超管或该业务负责人 |
| POST | `/member-imports` | 非固定业务/小组名单导入，预览与提交共用；提交需 `scope`，待确认行用 `approvals` 显式确认 | 超管或该业务负责人 |
| GET | `/member-imports` | 导入批次列表，可带 `business_id` | 超管或该业务负责人 |
| GET | `/member-imports/{batch_id}` | 批次明细、是否可撤销 | 同上 |
| POST | `/member-imports/{batch_id}/revert` | 撤销整批，限导入后 7 天内 | 同上 |
| DELETE | `/slots/{slot_id}/members/{student_id}` | 移出班次队员，只影响该班次，不删除账号 | 超管或该业务负责人 |
| PUT | `/business-groups/{group_id}/members/{student_id}` | 加入或移出小组成员，`active=false` 为移出，按生效日期收口 | 超管或该业务负责人 |

`/docs` 页的路由、参数与示例直接读取本机 `/openapi.json`，新增接口随服务重启自动出现；本表只补充权限口径。

## 设计方向与技能适用范围

本轮安装并阅读了 `design-taste-frontend`，来源为 `https://github.com/Leonxlnx/taste-skill`。该技能明确将密集后台、数据表格与多步骤产品界面列为非主要适用范围，因此本项目采用适合日常管理的克制布局，使用其上下文判断、排版层级、颜色一致性、反馈状态和响应式检查原则。未把宣传页的大幅动效、图片和营销内容要求套用到业务表格。

本项目是原生 HTML、CSS 和 JavaScript 实现，不宣称使用 Fluent、Carbon 或其他官方设计系统。v2.5 起采用「墨绿 / 纸白 / 浅绿 / 浅米色」配色：工作台以纸白底、墨色字和馆藏绿主色为主；登录与密码页采用墨绿主视觉 + 浅绿色表单区，字号较上一版整体 +1px，并按视口高度做 900 / 800 / 700px 三档压缩，保证 1366×768 笔记本一屏放下。具体取值为设计变化程度 3、动效强度 2、信息密度 5。无图片和远程字体依赖。

桌面使用侧栏、工作概览和表格；窄屏可切换导航菜单，表格容器允许横向查看。提供明暗外观、键盘焦点、跳转主要内容入口、原生模态对话框，以及加载、空记录和错误提示。只在系统允许动效时启用短促状态过渡。

v2.5 页面层（`web/pages-v25.css`）在此基础上统一了全部工作台业务页面：侧栏固定 264px、顶栏吸顶、页头操作右对齐；窄屏（≤767px）侧栏收为带遮罩的抽屉、按 Esc 关闭，工具栏与查询表单单列，表格自动变为「标签 + 值」卡片（由 `web/app.js` 按表头为单元格补充 `data-label`，仅浏览器环境生效），弹窗与征集弹窗接近全屏。概览页使用四指标卡 + 双栏布局，指标卡在 ≤1100px 变两列、≤480px 变单列。

## 中文化边界

业务导航、按钮、登录角色、状态、表单标签、错误提示及接口说明使用简体中文。接口协议字段（例如 `student_id`）、路径、HTTP 方法与枚举值仍保持原样；调用页面以中文标签辅助解释，避免破坏已有调用方。用户录入的姓名、学院和原因按原内容呈现，不强制翻译。

后端校验错误返回中文字段位置和说明，避免把无效密码等原始输入回显。接口文档从本机 `/openapi.json` 读取中文说明；脚本和样式从 `/static` 加载。

## 登录、时间与数据处理

- 登录令牌在当前标签页的 `sessionStorage` 中保存；工作台与接口文档使用同一令牌名称。外观偏好单独保存在 `localStorage`，支持浅色 / 深色 / 跟随系统三态，缺省跟随系统。
- 密码管理：修改密码必须已登录，在工作台左侧「修改密码」弹窗中输入**当前密码**、新密码与确认后提交；本地与后端都会拒绝「新密码与原密码一致」（红色提示「密码与原密码一致，请设置不同的新密码」）。成功后关闭弹窗，在页面顶部居中显示白色提示条「密码已更新，请牢记新密码」，旧密码立即失效，当前登录状态保持（接口未实现令牌吊销，旧令牌最长仍有效 1 小时）。忘记密码时无需登录，打开 `/password` 提交重置申请；申请进入超级管理员收件箱，由管理员核实身份并使用「重置密码」处理，为防账号枚举接口统一返回已受理。登录页只保留「忘记密码」入口，不提供修改密码入口。
- 服务日期、班次开始和结束时间按北京时间解释。创建与申请只能针对尚未开始的排班；考勤需等班次结束后提交。
- 工作台使用真实数据库。新增、审批、取消、考勤结算、时长修正和规则修改均通过对应接口提交，成功后刷新记录。
- 文本输入与数据库文本在插入 HTML 时进行转义；日志详情不呈现密码字段。
- 对话框保留失败时的输入与中文错误，便于修正后重试。

界面功能不能扩展后端尚未支持的业务。已结算考勤的改判、违规申诉与冲正、管理员交接和密码自助找回仍属于后续范围。

本文记录界面结构和设计选择；自动化检查和浏览器验收结果见 [验证记录](validation.md)。

固定时段与 Excel 预览导入的操作说明见 README。普通管理员新增“本时段队员”页，按完整学号精确查询。学院始终选填。

队员的工作概览及排班页面展示“我的固定班次”，读取本人 `slot_member` 归属。固定换班通过 `/applications/fixed-transfer` 提交，原时段负责人初审、超级管理员终审；终审检查在队状态、原归属、重复目标、时间冲突和人数上限，再原子替换固定班次。未设置容量或目标负责人时可以提交，补齐设置后才能终审。原时段没有负责人时，需要先分配负责人才能初审。

固定换班长期生效，不生成或改写已安排的日期排班。已有日期排班仍使用原来的单次请假、换班及考勤流程。管理员移除原归属、批准退队或信用归零时，未完成的固定换班申请自动取消。

设计规范 2.5.0 · 静态预览

这是“馆藏 · 纸墨”方向的静态预览：原生 HTML/CSS，零外部依赖，使用系统中文与假数据， 不连接正式系统、不修改任何产品代码。认证区采用 1:1 深绿封面与暖纸白身份扉页， 保留圆环和口号并移除功能宣传；其余工作台页面保持既有业务预览。请重点看构图、排版层级、表格密度与移动端形态。

打开方式：直接双击本页 index.html 即可；也可在浏览器地址栏打开同目录其他页面。 右上角按钮循环切换「浅色 / 深色 / 跟随系统」；窄屏或缩窄窗口可查看移动端布局；审批抽屉可按 Esc 关闭。

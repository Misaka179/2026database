# 前端设计规范 2.5.0 · 静态预览

> 状态：**设计预览（v2.5 已落地）**。2026-11-07 起，本目录的登录页、主题、密码页与组件样式已实现到正式前端（`web/app-v25.css`、`web/app.js`、`web/password.html`），预览目录保留为设计对照与后续迭代依据。
> 本目录不连接正式系统、不请求任何接口、不使用真实数据，也不修改 `web/` 下的产品代码。

## 打开方式

1. 双击本目录的 `index.html`（推荐 Chrome / Edge / Firefox）。
2. 从目录页进入 6 个预览；右上角按钮循环切换 **浅色 → 深色 → 跟随系统**。
3. 想看手机效果：打开 `mobile.html`（390×844 三屏对照），或把浏览器窗口缩窄到 390px 左右。

> 部分浏览器会限制本地 `file://` 页面嵌套 iframe；`mobile.html` 若空白，直接打开对应页面再缩窄窗口即可。

登录页与密码页按**视口高度**做了三档压缩（≤900 / ≤800 / ≤700px），已在 **1366×768** 与 **1536×864** 实测一屏放下、无需下滑；低于 700px 才允许页面滚动。

## 路由

预览用文件名 + 地址栏 hash 模拟正式前端的路由：

| 路由 | 页面 | 说明 |
|---|---|---|
| `login.html` | 登录 | 未登录入口 |
| `password.html#reset` | 忘记密码 | 登录页「忘记密码？」与「找回密码」进入 |
| `password.html#change` | 修改密码 | 登录页「修改密码」与工作台侧栏「修改密码」进入 |
| `overview.html` / `schedules.html` / `applications.html` | 工作台内页 | 已登录状态 |
| `index.html` / `mobile.html` | 预览目录 / 移动端对照 | 仅预览用 |

> `#reset` / `#change` 由 `preview.js` 的 `syncAuth()` 同步标签页与面板；正式实现时改为 SPA 路由状态或 `GET /reset-password` 页面。

## 重点观察项（建议逐条看）

1. **配色**：纸白 `#F7F6F1` 与纯白卡片是否层次清楚；馆藏绿 `#2D5B4B` 的主按钮是否足够稳；书脊铜只出现在「累计服务时长」上是否克制得当。
2. **排版层级**：概览页 28 / 18 / 14 / 12 的组合是否一眼能分出主次；表格 13px 是否仍好读。
3. **表格密度**：排班页一屏能看到多少行；表头吸顶、行悬停、状态徽章（颜色 + 文字 + 圆点）是否清楚。
4. **审批抽屉**：右侧抽屉 520px 宽、头部与底部固定、中部滚动是否适合连续审批。
5. **移动端**：缩窄窗口后侧栏是否变抽屉、列表是否变「标签 + 值」卡片、按钮是否够大。
6. **暗色**：切到深色后，卡片、描边、主色文字与状态色是否仍然清楚（不应出现浅色残留）。

## 已知限制

- 全部为假数据；登录、审批、分页等按钮不会真正提交，仅演示视觉与布局。
- **忘记密码 / 修改密码目前只有前端页面**：后端尚无自助找回与改密接口，需按下述方案补充接口后才能真实使用。
  - 忘记密码：提交重置申请 → 管理员核实后使用现有「重置密码」接口处理（可复用现有权限与审计，无需新增验证通道）。
  - 修改密码：新增 `POST /auth/password/change`（校验当前密码、写入新哈希、吊销旧令牌）。
- 字体使用系统中文（PingFang / 微软雅黑 / Noto Sans CJK），不做远程字体加载。
- 图标为内联 SVG（`preview.js` 中定义），不使用图标字体或图片。
- 交互（主题、折叠、抽屉、标签页、密码页路由）用少量 JS 实现，仅用于预览；正式实现会基于现有 `web/*.js` 改造。

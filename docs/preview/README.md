# 前端设计规范 2.5.0 · 静态预览

> 状态：**设计预览（认证区 2026-11-12 馆藏编辑风）**。本目录的登录页、找回密码页、主题和组件样式用于对照正式前端；工作台预览仍保留 v2.5 业务页面示意。
> 本目录不连接正式系统、不请求任何接口、不使用真实数据，也不修改 `web/` 下的产品代码。`screens/` 中的旧 PNG 是 2026-11-07 的历史截图，不代表本轮认证页视觉。

## 打开方式

1. 双击本目录的 `index.html`（推荐 Chrome / Edge / Firefox）。
2. 从目录页进入 6 个预览；右上角按钮循环切换 **浅色 → 深色 → 跟随系统**。
3. 想看手机效果：打开 `mobile.html`（390×844 三屏对照），或把浏览器窗口缩窄到 390px 左右。

> 部分浏览器会限制本地 `file://` 页面嵌套 iframe；`mobile.html` 若空白，直接打开对应页面再缩窄窗口即可。

认证页桌面端采用 46:54 封面/扉页构图，大圆环、单根铜色书脊线和编辑排版是主要识别元素；移动端保留约 168px 的深绿封面条。页面按 **1366×768、1440×900、768px、390×844** 视口检查无横向溢出；桌面扉页不使用内部滚动。

## 路由

预览用文件名 + 地址栏 hash 模拟正式前端的路由：

| 路由 | 页面 | 说明 |
|---|---|---|
| `login.html` | 登录 | 未登录入口 |
| `password.html#reset` | 忘记密码 | 登录页「忘记密码？」与「找回密码」进入 |
| `password.html#change` | 旧改密链接兼容 | 显示“请登录后在工作台修改密码”，随后规范化到 `#reset` |
| `overview.html` / `schedules.html` / `applications.html` | 工作台内页 | 已登录状态 |
| `index.html` / `mobile.html` | 预览目录 / 移动端对照 | 仅预览用 |

> 预览只有 `#reset` 找回表单；`#change` 仅用于演示旧链接兼容，不再切换第二套改密表单。

## 重点观察项（建议逐条看）

1. **认证构图**：深绿 `#173F34` 封面与暖纸白 `#F4F1E8` 扉页是否形成明确的 46:54 节奏；大圆环是否穿过口号而非漂浮在背景。
2. **配色与材质**：纯象牙白控件、暖灰边框和书脊铜 `#9B7447` 是否层次清楚；自动填充时不应出现蓝底。
3. **排版层级**：概览页 28 / 18 / 14 / 12 的组合是否一眼能分出主次；表格 13px 是否仍好读。
4. **表格密度**：排班页一屏能看到多少行；表头吸顶、行悬停、状态徽章（颜色 + 文字 + 圆点）是否清楚。
5. **审批抽屉**：右侧抽屉 520px 宽、头部与底部固定、中部滚动是否适合连续审批。
6. **移动端**：缩窄窗口后侧栏是否变抽屉、列表是否变“标签 + 值”卡片、认证页是否保留 168px 封面识别度。
7. **暗色**：切到深色后，封面、纸面、控件、描边和状态色是否仍然清楚（不应出现浅色残留）。

## 已知限制

- 全部为假数据；登录、审批、分页等按钮不会真正提交，仅演示视觉与布局。
- 预览页不连接接口、不写入数据；正式页面已经提供 `POST /auth/password/reset-request` 与 `POST /auth/password/change`。找回表单的精确匹配、HTTP 422 文案、通知去重和改密成功后退出登录行为以正式页面与接口文档为准。
- 字体使用系统中文（PingFang / 微软雅黑 / Noto Sans CJK），不做远程字体加载。
- 图标为内联 SVG（`preview.js` 中定义），不使用图标字体或图片。
- 交互（主题、折叠、抽屉、旧 `#change` 兼容提示）用少量 JS 实现，仅用于预览；正式实现由现有 `web/*.js` 提供。
